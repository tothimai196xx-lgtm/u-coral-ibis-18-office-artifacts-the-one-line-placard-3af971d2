A program that writes one line — a museum placard for an ordinary office
object treated as an ancient artifact — to `/output/entry.txt`.

The placard (172 characters, one line):

> Fax machine, c. 1995, beige plastic. Shrine of the long-distance scream: it ate paper in one city and wept it out in another. Its last transmission was a lunch order, 2009.

Run with Node 22.18 or later:

```
node main.ts
```

It writes exactly that line (no trailing newline) to `/output/entry.txt`.
